# How to build the nano duck

Generated by `tools/nano_docs.py` from the order in `spec/nano_duck.py`, which `tools/assembly.py` checks: every part has a straight way in, every screw a key's reach and a bite. The right leg is the left's mirror. Set each servo to mid-range (1500 us) before its horn goes on. Parts: [BOM.md](BOM.md); wiring: [WIRING.md](WIRING.md).
